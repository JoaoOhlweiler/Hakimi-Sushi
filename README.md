# Hakimi-Sushi
### Hakimi Sushi

Site desenvolvido para o Hakimi Sushi, com o objetivo de apresentar o restaurante, destacar seu ambiente e proporcionar uma experiência agradável e intuitiva aos visitantes.

### Sobre o projeto

O Hakimi Sushi é um projeto de desenvolvimento web simples criado para apresentar a identidade do restaurante na internet, reunindo informações importantes em um único lugar.
Fiz esse site para servir como primeiro projeto, sendo uma aplicação focada em Front-End com funcionalidades básicas web, ficando marcado então como meu primeiro projeto.


### Funcionalidades

Página inicial com apresentação do restaurante; <br>
Seção de apresentação e informações sobre o estabelecimento;<br>
Exibição de imagens;<br>
Área de avaliações e comentários;<br>
Sistema de classificação por estrelas;<br>
Informações sobre horários de atendimento;<br>
Localização do restaurante com integração ao Google Maps;<br>
Animações e efeitos visuais durante a navegação;<br>
Layout adaptável a diferentes tamanhos de tela.<br>

### Tecnologias utilizadas

HTML5 — Estruturação das páginas; <br>
CSS3 — Estilização, layout, responsividade e animações;<br>
JavaScript — Interatividade e funcionalidades dinâmicas.

### Como executar o projeto:

Faça o download ou clone este repositório;<br>
Abra a pasta do projeto;<br>
Execute o arquivo index.html no navegador;<br>
Para facilitar o desenvolvimento, recomenda-se utilizar o Live Server no Visual Studio Code.

### Objetivo

Este projeto também faz parte do meu processo de aprendizado e evolução no desenvolvimento Front-End, colocando em prática conhecimentos de HTML, CSS e JavaScript por meio da criação de um site funcional e visualmente atrativo.<br>
